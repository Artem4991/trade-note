# Trade Note

Offline-first приложение для ведения личного инвестиционного портфеля. Первая версия работает локально в браузере и не требует сервера.

## Стек

- Vue 3 и TypeScript
- Vite
- Naive UI
- pnpm workspaces
- Feature-Sliced Design
- ESLint, Prettier и Vitest

## Быстрый старт

```bash
pnpm install
pnpm dev
```

Основные проверки:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
