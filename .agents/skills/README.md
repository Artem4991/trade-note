# Repository skills

Локальные skills этого репозитория размещаются по одному в отдельной папке:

```text
.agents/skills/
└── skill-name/
    ├── SKILL.md
    ├── references/  # при необходимости
    ├── scripts/     # при необходимости
    └── assets/      # при необходимости
```

Минимальный `SKILL.md`:

```md
---
name: skill-name
description: Когда агент должен использовать этот навык.
---

Краткие пошаговые инструкции для повторяемого workflow.
```

Не создавайте skill для одноразовой задачи. Навык должен описывать повторяемый процесс и оставаться достаточно узким, чтобы срабатывать предсказуемо.
