# Продукт Trade Note

## Цель

Создать offline-first приложение для ведения личного инвестиционного портфеля. Пользователь вручную управляет валютами и активами и видит стоимость портфеля в нескольких валютах.

## Сценарий MVP

1. Пользователь создаёт портфель.
2. Добавляет валюты и ручные курсы.
3. Добавляет акции, криптовалюты, облигации и индексы с ценой и количеством.
4. Изменяет или удаляет позиции.
5. Видит общую стоимость портфеля в USD, RUB и BYN.

В MVP один пользователь, один экран портфеля и локальное хранение в браузере. Котировки и курсы вводятся вручную.

## Интерфейс

- Два адаптивных режима: mobile/tablet и desktop.
- Готовые компоненты предоставляет Naive UI.
- После рабочего MVP планируются графики и PWA-режим.

## Не входит в текущий MVP

- Авторизация и несколько пользователей.
- Автоматическая загрузка котировок и курсов.
- Импорт из CSV.
- Несколько брокерских счетов.
- Серверная база данных, API и синхронизация между устройствами.

## Будущее направление

После стабилизации локальной модели можно добавить графики, автоматическое получение данных и отдельное серверное приложение. Эти возможности не должны усложнять текущую реализацию заранее.
